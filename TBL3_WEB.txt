EXEC 1

Instalação do pacote:

  npm install cors

Trecho do servidor que habilita o CORS:

  const express = require('express');
  const cors = require('cors');

  const app = express();

  app.use(cors());

Com o middleware ativo, toda resposta da API passa a incluir o cabeçalho
"Access-Control-Allow-Origin: *". Isso informa ao navegador que qualquer
origem pode ler a resposta. A rota /usuarios continuou respondendo
normalmente depois da alteração.

  requested resource.

Por que a chamada funciona no Postman e falha no navegador?

O CORS é regra do navegador, que checa se tem Access-Control-Allow-Origin, nao do servidor. 
Como o POSTMAN nao é navegador, funciona normalmente

EXEC3

  app.use(cors({
    origin: 'http://localhost:5500'
  }));

Teste com o frontend em http://localhost:5500: a requisição funcionou e o
console exibiu a lista de usuários.

O que acontece quando a página é executada por uma origem diferente?

Nao funciona, pois o navegador confere o que vem no cabeçalho com a origem da pagina,
como nao sao iguais, nao permite.

EXEC 5

  app.use(cors({
    origin: 'http://localhost:5500',
    methods: ['GET']
  }));

Objetivo de limitar os métodos permitidos:

Para limitar o que a pagina pode fazer. Nao faz sentido permitir que scripts de outra
origem rodem se ela apenas consuta dados
